# Touristikseite (Demo)

Fiktive Webseite eines Tourismusanbieters („Hochalp Erlebnis“). Sie zeigt, wie der
Panoramaviewer von https://ram1630.github.io/panoramaview/ per `<iframe>` in eine fremde Seite eingebettet wird.

Alle Angaben sind erfunden, „Hochalp Erlebnis“ ist kein echtes Unternehmen.

## Einbettung

```html
<iframe src="https://ram1630.github.io/panoramaview/?scene=berg&nav=0&autorotate=-2"
        title="360°-Panorama der Bergstation" allowfullscreen loading="lazy"></iframe>
```
